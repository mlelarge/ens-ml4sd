# Machine Learning for Scientific Discovery

*From Foundations to Applications*

**ENS · 2026** — Marc Lelarge and Tony Bonnaire

This course introduces the foundations of machine learning, from statistical models to modern deep learning, with a focus on scientific research. Students will learn the methods and computational tools needed to apply machine learning to data and problems in their own field.

The core curriculum builds a foundation in statistical learning and practical skills with scikit-learn and PyTorch. It is followed by six weeks of research projects proposed and supervised by the participating departments.

## Prerequisites

- Basic knowledge of calculus and linear algebra.
- Basic knowledge of probability and statistics.
- Proficiency in Python — see the [Python and NumPy tutorial](https://cs231n.github.io/python-numpy-tutorial/) for a refresher.
- Get familar with the [Datalab plateform](https://datalab.sspcloud.fr/) (GPUs are available)
